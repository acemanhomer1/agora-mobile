# Agora Mobile

This repository builds two Android applications:

- **Agora** — the regular participant app.
- **Agora Owner** — the owner's separate entry point.

Both apps display the live Agora service in a dedicated Android application.
GitHub Actions builds installable debug APKs after every push to main.

## Downloading a build

Open the latest **Build Agora Android Apps** workflow run, then download:

- Agora-Android
- Agora-Owner-Android

Each download is a ZIP containing its APK.
